# Item, box and equipment art

Drop a `.webp` (or `.png`) here and the game uses it instead of the emoji. No code change is needed.

File name: `<kind>-<id>.webp`

| kind        | ids                                                                                         |
|-------------|----------------------------------------------------------------------------------------------|
| `box`       | `bronze`, `silver`, `gold`, `choice`                                                          |
| `item`      | `happy-hour`, `xp-boost`, `coin-boost`, `tip-boost`, `vip-magnet`, `golden-ice`, `voucher`, `second-chance`, `calm-charm`, `whisper`, `steady-hand`, `courier`, `scroll` |
| `equipment` | `shaker`, `ice-machine`, `fridge`, `speakers`, `register`, `cellar`                           |

Examples: `box-gold.webp`, `item-golden-ice.webp`, `equipment-fridge.webp`.

Size: square, transparent background, 256 x 256 px is plenty (it is shown at 40-64 px). Keep each file under about 40 KB.
